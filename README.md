## Why NearU?

NearU provides event organizers with an intuitive, self-hosted or cloud discovery and ticketing platform where you own your attendee relationships, checkout experience, and brand:

- **Zero forced middlemen fees**: Connect your own Stripe account for direct, instant payouts.
- **Deep discovery & engagement**: Clean, responsive interfaces optimized for both mobile attendees and desktop organizers.
- **Complete data ownership**: All customer and event records remain within your database.

<br>

## Key Features

**📅 Events & Discovery**
- Single and recurring event schedules with flexible dates, times, and venue locations
- Interactive event discovery and customized organizer homepages
- Built-in visual event page designer
- Lineup, artist, and schedule showcases

**🎟️ Flexible Ticketing**
- Free, paid, tiered, donation, and group tickets
- Add-ons, merchandise, and hidden access tiers unlocked via promo codes
- Per-order limits, real-time capacity management, and automatic waitlists
- Reserved seating maps

**🛒 Embedded Checkout**
- Seamless embeddable widgets and responsive checkout flow for any website
- Promotional codes, affiliate tracking links, and custom attendee questionnaires
- Conversion tracking (Meta Pixel, Google Tag Manager, TikTok)

**💳 Direct Payments**
- Direct Stripe integration for instant payouts
- Multi-currency support, custom tax rates, and offline payment recording
- Full and partial refund workflows

**🚪 Door Management & Check-in**
- Mobile camera and USB scanner QR code check-in
- Live door counts and synchronized attendee check-in lists
- Automated order confirmation, custom email notifications, and branded PDF tickets

## Tech Stack

- **Backend**: Laravel 13 (PHP >=8.3), PostgreSQL, Redis, MinIO (S3 compatible)
- **Frontend**: React 19 SSR, Vite, TypeScript, Mantine UI, Lingui i18n
- **Infrastructure**: Docker & Docker Compose, Nginx reverse proxy

## Quick Start (Development)

### Prerequisites

- [Docker](https://www.docker.com/) & Docker Compose
- Node.js (v20+) & Yarn (optional for local frontend tooling)
- PHP 8.3+ & Composer (optional for local backend CLI)

### Running with Docker

1. Clone or extract the project workspace:
   ```bash
   cd junction
   ```

2. Start the development stack:
   ```bash
   # Windows PowerShell
   cd docker/development
   docker compose -f docker-compose.dev.yml up -d
   ```

3. Initialize backend keys & run migrations:
   ```bash
   docker compose -f docker-compose.dev.yml exec backend php artisan migrate
   ```

4. Access the application:
   - **Frontend Application**: `https://localhost:8443`
   - **Mailpit (Local Emails)**: `http://localhost:8025`
   - **MinIO Console**: `http://localhost:9001`

## Configuration & White-Label Customization

NearU supports extensive white-labeling out of the box via environment variables:

| Variable | Description | Default |
|---|---|---|
| `APP_NAME` | Backend application name | `NearU` |
| `VITE_APP_NAME` | Frontend brand name | `NearU` |
| `VITE_APP_LOGO_DARK` | Primary dark theme logo URL | `/logos/nearu-horizontal-light.svg` |
| `VITE_APP_LOGO_LIGHT` | Primary light theme logo URL | `/logos/nearu-text-dark.svg` |
| `VITE_APP_FAVICON` | Browser favicon URL | `/manifest-icons/favicon.svg` |
| `VITE_FRONTEND_URL` | Application root URL | `https://localhost:8443` |
